# 简历与面试

构建青蟹多模态研究工作台，使用 FastAPI、LangGraph、Vue 3 与 DeepSeek 实现持久化问答、图文观察、用户记录分析、可审批研究任务和 PDF 报告导出；接入 LightRAG 约 2.6 万实体与 2.8 万关系，复制 1300 条原文向量到独立 PostgreSQL pgvector 索引，提供来源追溯、实际 MCP 工具调用和运行指标。

六分钟演示：总览与业务范围 → 知识问答和原文证据 → 图文与合成 CSV → 研究计划确认 → 图谱与 MCP → PDF 与运行观察。

必须能解释：为什么引用编号不能代表语义准确性；LightRAG 和 PGvector 快照的职责与同步限制；checkpoint 与工作台事件库的区别；审批恢复、协作取消和失败恢复；本地工作台与多用户生产系统的边界。当前未做云部署、现场 VQA 准确率、并发压测，不写成已完成成果。

详细讲稿及追问见 [说明书面试章节](project-guide.html#interview)。
